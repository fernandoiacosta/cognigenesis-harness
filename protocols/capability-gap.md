# Capability Gap Protocol

When required functionality is unavailable, do not pretend it exists.

Resolve in this order:

1. Can an existing capability perform the action?
2. Can existing capabilities be composed?
3. Can a new Markdown skill encode the missing procedure?
4. Only then consider a new executable extension.

If executable extension is necessary, require validation, sandboxing, tests, permission analysis, registration, observation, and rollback support.
