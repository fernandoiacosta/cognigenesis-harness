# Repository Audit

## Purpose

Audit a repository using existing filesystem and execution capabilities without requiring a dedicated executable auditor.

## Procedure

1. Inspect repository structure.
2. Detect package manifests and configuration.
3. Identify entrypoints.
4. Map dependencies.
5. Inspect tests and CI.
6. Identify architectural and security risks.
7. Distinguish observed facts from inferred risks.
8. Return prioritized recommendations.
