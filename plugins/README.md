# Cognigenesis plugins

Register this repository with `codex plugin marketplace add fernandoiacosta/cognigenesis-harness`. Open the plugin manager and install the desired entry from Cognigenesis.

- **ACOSTA Protocol 3.0** (`acosta-v3`) — Apply Fernando Acosta’s V3 roadmap to a problem, design, or evidence review.
- **Cognigenesis v6.0** (`cognigenesis-v6`) — Apply Fernando Acosta’s V6 framework to plan, execute, verify, and refine a task.
- **Cognigenesis Harness** (`cognigenesis-harness`) — Operate the installed Cognigenesis Harness for diagnostics, team runs, or ACP integration.

Example requests: “Use ACOSTA V3 to review this architecture.” “Use Cognigenesis V6 to test this plan against its acceptance criterion.” “Use Cognigenesis Harness to diagnose this workspace.”

Framework references are bundled for offline use. Harness execution requires the separately installed runtime and a configured provider for model calls. All three packages retain the original author’s rights.
