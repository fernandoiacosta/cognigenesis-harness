# ACOSTA Protocol 3.0

Read `reference.md` beside this file. Identify the user's decision, constraints, and observable success condition. Select the roadmap mechanisms relevant to that decision. For example, use a knowledge graph to track dependencies, or combine explicit rules with pattern evidence to check a classification. Develop a candidate answer, challenge its weakest assumption, and identify what observation would change it. Return the result and the most informative next check. Describe simulations and proposed hardware accurately. Distinguish the roadmap's ambitions from demonstrated capabilities.
