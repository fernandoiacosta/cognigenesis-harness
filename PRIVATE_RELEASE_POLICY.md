## Classification

This repository contains a private operational implementation associated with Cognigenesis, authored by Fernando Acosta. It is not approved for public release.

Repository access, development assistance, testing, or maintenance does not grant authorship, ownership, a license, publication authority, or permission to use the contents for model training.

## Prohibited without Fernando Acosta's explicit authorization

- Making the repository public or creating a public mirror
- Publishing packages, binaries, demos, screenshots, prompts, architecture details, or benchmark outputs
- Disclosing orchestration, security, verification, agent, memory, routing, or evaluation mechanisms
- Sharing credentials, environment data, private endpoints, experiment artifacts, or user information
- Representing unreplicated tests as established performance claims

## Release gate

A public release requires all of the following:

1. Fernando Acosta approves the exact commit and files.
2. Secrets and sensitive implementation details are removed.
3. Authorship and provenance statements are intact.
4. Claims are traceable to preserved evidence and distinguish fact, inference, and hypothesis.
5. Licensing and intellectual-property implications have been reviewed.
6. A private, restorable copy of the pre-release state exists.

Silence, repository access, or prior authorization for a different artifact is not authorization to publish this repository.
